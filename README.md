# BigAuth : Secure Authentification

## What's BigAuth ?
BigAuth is a little project setup by me to understand how Node.JS does really work especially in authentification. Some functionnalities can be incomplete right now, because i'm working on it.
The object of this project is not to be perfect, but it is just thing for me to present the result of my work on Node.JS (and HTML, CSS and JavaScript).

## How to try it ?

To try it, you just have to open a terminal on the main folder and write this :
```bash
# Used to install all the dependencies needed by the project
npm install

# Used to start the server. You should see something like 'Server connected on http://localhost:3000' and 'Connected to MySQL'
node index.js
```
After that, you have to open index.html file (on views folder)
